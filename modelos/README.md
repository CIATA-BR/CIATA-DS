# Modelos reutilizáveis

Esta pasta concentra modelos institucionais que podem ser adaptados para novos materiais sem alterar os arquivos mestres.

## Conteúdo previsto

- documentos;
- apresentações;
- publicações para redes sociais;
- capas e banners;
- certificados;
- peças para eventos;
- assinaturas e elementos institucionais.

## Regra de uso

O arquivo mestre deve permanecer preservado. Novas peças devem ser criadas por cópia e receber nome, data e versão próprios.

Materiais derivados precisam manter identidade visual, legibilidade, contraste e compatibilidade com tecnologias assistivas.
