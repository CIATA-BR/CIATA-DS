# Padrões de solução

Padrões documentam soluções recorrentes. Eles explicam **quando usar**, **quando evitar**, quais problemas resolvem e quais cuidados de acessibilidade, segurança e manutenção acompanham a escolha.

## Estrutura mínima

Cada padrão deve conter:

- nome compreensível e identificador `PAT-0000`;
- problema e contexto;
- solução proposta;
- quando usar e quando não usar;
- exemplo de aplicação;
- acessibilidade;
- riscos e antipadrões;
- relações com especificações, decisões, checklists e receitas.

## Regra de comunicação

Não diga apenas “use o PAT-0003”. Diga “use o padrão de formulário acessível PAT-0003”. O código localiza; o nome comunica.
