# Playbooks operacionais do CIATA

Os playbooks descrevem como executar processos recorrentes do CIATA de forma clara, acessível, auditável e reutilizável.

## Convenção

Cada playbook possui identificador permanente no formato `PB-NNNN`, versão, status, responsáveis, entradas, etapas, critérios de conclusão, evidências e relacionamentos.

## Catálogo inicial

- `PB-0001` — iniciar novo projeto;
- `PB-0002` — receber novo colaborador;
- `PB-0003` — publicar uma release;
- `PB-0004` — aprovar um artefato institucional;
- `PB-0005` — executar validação manual de acessibilidade;
- `PB-0006` — propor mudança por RFC.

## Regras gerais

- etapas críticas não podem ser ignoradas sem justificativa;
- toda execução deve deixar evidências rastreáveis;
- automação pode apoiar, mas não substituir validações humanas obrigatórias;
- informações sensíveis não devem ser registradas em repositórios públicos;
- instruções devem funcionar com teclado, leitores de tela e linhas Braille;
- atalhos devem ser escritos com os nomes completos das teclas.
