# Ferramentas de acessibilidade

Esta área documenta ferramentas de inspeção, automação, simulação, monitoramento e apoio a testes.

Cada guia deve informar finalidade, instalação, configuração, cobertura, limitações, falsos positivos, falsos negativos, formatos de saída e integração possível.

Ferramentas não substituem testes manuais nem avaliação com tecnologias assistivas. Resultados automáticos são evidências parciais e devem ser interpretados no contexto do produto.
