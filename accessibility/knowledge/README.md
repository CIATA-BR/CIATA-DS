# Conhecimento aplicado de acessibilidade

Esta área preserva conhecimento confirmado e reutilizável produzido por projetos, auditorias, incidentes e pesquisas.

Conteúdos futuros incluirão bugs conhecidos, anti-padrões, estudos de caso, lições aprendidas, glossário e diferenças de interoperabilidade.

Cada registro técnico deve informar origem, contexto, versões, evidência, impacto, solução ou contorno, status e data da última verificação. Conhecimento superado permanece rastreável e deve indicar claramente sua substituição.
