# Plataformas

Esta área documenta acessibilidade por sistema operacional, ambiente, framework e modelo de interface.

Conteúdos futuros incluirão Web, Android, iOS, Windows, macOS, Linux e documentos digitais.

Cada guia deve registrar semântica nativa, APIs, foco, teclado, gestos, conteúdo, limitações, versões e estratégias de teste. Exemplos específicos não devem substituir princípios compartilhados.
