# Receitas de acessibilidade

Esta área transforma padrões em soluções reproduzíveis por plataforma, framework ou tecnologia.

Cada receita deve conter:

- problema e resultado esperado;
- contexto e pré-condições;
- implementação recomendada;
- alternativa quando necessário;
- exemplo incorreto e motivo;
- procedimento de teste;
- tecnologias assistivas consideradas;
- limitações e versões conhecidas;
- referências ao padrão e às normas relacionadas.

Receitas não devem esconder complexidade relevante nem prometer compatibilidade universal sem evidências.
