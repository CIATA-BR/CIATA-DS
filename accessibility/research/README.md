# Pesquisa em acessibilidade

Esta área recebe hipóteses, experimentos, comparações, provas de conceito, benchmarks e análises de versões em evolução.

Pesquisa não consolidada deve indicar pergunta, método, ambiente, amostra, limitações, resultado e nível de confiança. Conteúdo experimental não deve ser apresentado como padrão oficial.

Quando uma descoberta for reproduzida, revisada e aplicável a outros projetos, ela poderá ser promovida para `knowledge`, `patterns`, `recipes` ou outra área canônica, preservando a referência à pesquisa de origem.
