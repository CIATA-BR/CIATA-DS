# CIATA Accessibility Engineering System

O CIATA Accessibility Engineering System organiza princípios, padrões, evidências, práticas e conhecimento aplicado para projetar, desenvolver, testar, publicar e evoluir produtos digitais inclusivos.

Seu objetivo não é apenas apoiar conformidade normativa. O sistema transforma experiência prática em decisões de engenharia reutilizáveis, para que acessibilidade não dependa da memória de uma pessoa, de uma auditoria tardia ou de correções isoladas.

## Propósito

Este sistema existe para:

- incorporar acessibilidade desde requisitos, arquitetura e conteúdo;
- conectar normas, leis, plataformas e tecnologias assistivas;
- orientar implementação, testes, documentação e release;
- registrar evidências, limitações, exceções e decisões;
- preservar descobertas de projetos reais;
- oferecer fontes claras para pessoas e agentes de IA;
- permitir que cada projeto comece em um patamar mais alto que o anterior.

## O que este sistema não é

Não é uma certificação própria, um substituto para normas oficiais nem uma coleção de checklists desconectados. É uma camada de engenharia que traduz requisitos e experiência real em práticas reproduzíveis.

## Relação com os demais sistemas

O Brand System assegura identidade perceptível e coerente. O Design System define experiências e componentes. O Engineering System estabelece arquitetura, qualidade e entrega. O Accessibility Engineering System atravessa todos eles, especificando condições para uso real por pessoas com diferentes necessidades, tecnologias e contextos.

## Regra de promoção do conhecimento

Uma descoberta nasce em um projeto ou pesquisa. Quando confirmada e reutilizável, é documentada como conhecimento. Quando orienta decisões recorrentes, torna-se padrão. Quando pode ser aplicada diretamente, torna-se receita. Mudanças relevantes preservam origem, evidência e histórico.

## Regra de ouro

> Toda experiência adquirida durante um projeto deve ter o potencial de se transformar em conhecimento reutilizável para os próximos projetos.
