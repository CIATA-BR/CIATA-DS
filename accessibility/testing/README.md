# Testes de acessibilidade

Esta área define validação manual, automatizada, regressiva e de release.

A estratégia de testes deve combinar inspeção de código e semântica, ferramentas automáticas, teclado, recursos de tecnologia assistiva, diferentes configurações e avaliação humana da experiência.

Cada procedimento deve informar escopo, ambiente, dados, passos, resultado esperado, evidência e limitações. A aprovação de release deve ser proporcional ao risco e impedir a publicação de barreiras críticas conhecidas sem decisão formal registrada.
