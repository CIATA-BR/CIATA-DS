# Padrões de acessibilidade

Esta área descreve resultados de interação acessível para componentes, fluxos e estruturas recorrentes.

Conteúdos futuros incluirão formulários, navegação, diálogos, listas, tabelas, árvores, mídia, chats, mapas, autenticação e experiências com IA.

Um padrão deve explicar propósito, pessoas impactadas, semântica, foco, teclado, gestos, estados, feedback, erros, Braille, redução de movimento e critérios de teste. O padrão permanece independente de tecnologia; implementações concretas pertencem às receitas.
