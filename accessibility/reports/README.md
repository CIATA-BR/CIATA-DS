# Relatórios e evidências

Esta área padroniza auditorias, avaliações, pareceres, matrizes de conformidade e comunicação de resultados.

Relatórios devem registrar escopo, versões, métodos, critérios aplicáveis, itens não avaliados, evidências, severidade, impacto, recomendações, responsáveis e limitações.

Resultados não devem ser apresentados como conformidade total quando a amostra, o ambiente ou o método forem parciais. Modelos futuros poderão apoiar relatórios HTML, PDF, documentos editáveis, ACR e VPAT quando aplicável.
