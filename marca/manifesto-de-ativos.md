## Validação

Em Linux ou macOS:

```bash
sha256sum marca/logotipos/* marca/manual/manual-de-marca-ciata-2025.pdf
```

No Windows PowerShell:

```powershell
Get-FileHash marca/logotipos/*, marca/manual/manual-de-marca-ciata-2025.pdf -Algorithm SHA256
```

Qualquer divergência de hash deve ser tratada como uma versão diferente do ativo e exige revisão antes da publicação.
