# Marca

Este diretório reúne os elementos oficiais da identidade visual do CIATA.

## Estrutura prevista

- `manual/`: manual de marca e orientações institucionais.
- `logotipos/`: versões horizontal, vertical, símbolo, monocromática e negativa.
- `paleta-de-cores/`: cores oficiais e equivalências para impressão e meios digitais.
- `tipografia/`: especificações tipográficas e orientações de uso.
- `icones/`: ícones institucionais e símbolos complementares.

## Regras

- Não distorcer, inclinar ou reconstruir o logotipo.
- Preservar proporções e área de proteção.
- Usar apenas versões aprovadas.
- Não depender exclusivamente de cor para transmitir informação.
- Registrar formatos, dimensões, versão, autoria e licença quando aplicável.
