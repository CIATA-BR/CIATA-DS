# Receitas técnicas

Receitas técnicas mostram como implementar uma solução específica e reproduzível. São o cookbook do CIATA, sem ingredientes secretos guardados na cabeça de uma única pessoa.

## Diferença para outros documentos

- um procedimento operacional explica como a organização executa um processo;
- um padrão explica uma solução recorrente e seus limites;
- uma receita técnica mostra uma implementação concreta;
- um blueprint reúne uma base completa de projeto.

## Estrutura mínima

Cada receita deve conter:

- título claro e identificador `REC-0000`;
- objetivo e cenário de uso;
- pré-requisitos;
- dependências e versões testadas;
- passos numerados;
- exemplos copiáveis e adaptáveis;
- validação do resultado;
- acessibilidade, segurança e privacidade;
- erros comuns e recuperação;
- manutenção e atualização;
- documentos relacionados.

## Regra de qualidade

Uma pessoa que não participou da criação deve conseguir executar a receita. Comandos, atalhos e controles devem ser descritos textualmente, sem depender apenas de ícones, cores ou posição visual.

## Catálogo inicial planejado

- envio de e-mail pelo Microsoft Graph;
- autenticação OAuth;
- upload privado de arquivos;
- integração com OpenAI API;
- publicação Android e símbolos de depuração;
- CI/CD com GitHub Actions;
- internacionalização em Laravel, Android e iOS.
