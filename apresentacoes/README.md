# Apresentações

Esta pasta reúne apresentações oficiais do CIATA para diferentes contextos.

## Categorias previstas

- `institucional/`: apresentação geral do CIATA;
- `projetos/`: apresentações de iniciativas e produtos;
- `captacao/`: materiais para parcerias, patrocínios e editais;
- `eventos/`: palestras, oficinas e encontros.

## Padrões

As apresentações devem:

- manter identidade visual consistente;
- evitar excesso de texto por slide;
- usar contraste adequado;
- possuir títulos únicos e descritivos;
- preservar ordem de leitura lógica;
- incluir descrição para imagens relevantes;
- não depender apenas de cor, posição ou animação para transmitir informação.
