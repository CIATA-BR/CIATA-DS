# Convenções de Nomenclatura

## Objetivo

Este documento padroniza os nomes utilizados para todos os arquivos do Mascote CIATA.

A padronização facilita automação, reutilização, organização e integração entre projetos.

---

## Idioma

Os nomes de arquivos deverão utilizar inglês.

Utilizar apenas letras minúsculas.

---

## Separadores

Utilizar hífen (`-`) entre palavras.

Exemplo:

```
mascot-reading.png
```

---

## Prefixo

Todos os arquivos deverão iniciar com:

```
mascot-
```

---

## Exemplos

Poses

```
mascot-wave.png
mascot-reading.png
mascot-thinking.png
mascot-happy.png
mascot-loading.png
mascot-error.png
```

Tecnologias assistivas

```
mascot-wheelchair.png
mascot-white-cane.png
mascot-hearing-aid.png
mascot-cochlear-implant.png
mascot-braille-display.png
```

Braille

```
mascot-braille-slate.png
mascot-braille-stylus.png
mascot-perkins.png
```

LIBRAS

```
mascot-libras-welcome.png
mascot-libras-thanks.png
```

Projetos

```
mascot-portal.png
mascot-comunica.png
mascot-library.png
mascot-employability.png
```

---

## Versões

Quando necessário utilizar:

```
-v1
-v2
-final
```

Evitar:

```
novo.png
novo2.png
teste.png
final2.png
```

---

## Arquivos fonte

Os arquivos editáveis deverão manter o mesmo nome do arquivo exportado.

Exemplo:

```
mascot-wave.blend
mascot-wave.svg
mascot-wave.png
```

---

## Compatibilidade

As convenções deste documento deverão ser utilizadas em todos os projetos do CIATA.
