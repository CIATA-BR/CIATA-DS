# Organização de Assets

## Objetivo

Este documento define a organização dos arquivos relacionados ao Mascote CIATA.

Seu objetivo é manter uma estrutura consistente, facilitar reutilização entre projetos e garantir a preservação da identidade institucional.

Este documento não define a criação de imagens, apenas sua futura organização.

---

## Estrutura planejada

```
imagens/
└── mascote/
    ├── README.md
    ├── poses/
    ├── expressions/
    ├── accessories/
    ├── scenes/
    └── 3d/
```

---

## Diretório principal

```
imagens/mascote/
```

Concentrará todos os materiais oficiais do mascote.

Nenhum ativo experimental deverá permanecer neste diretório.

---

## Poses

```
imagens/mascote/poses/
```

Contém as poses oficiais.

Exemplos:

- boas-vindas
- acenando
- lendo
- comemorando
- erro
- carregando

---

## Expressões

```
imagens/mascote/expressions/
```

Destinado às expressões faciais oficiais.

Exemplos:

- feliz
- curioso
- atento
- concentrado
- preocupado
- comemorando

---

## Acessórios

```
imagens/mascote/accessories/
```

Armazena elementos reutilizáveis.

Exemplos:

- reglete
- punção
- notebook
- cadeira de rodas
- bengala
- linha Braille

---

## Cenários

```
imagens/mascote/scenes/
```

Destinado às composições completas utilizadas pelos projetos do CIATA.

Cada cena poderá reutilizar poses e acessórios existentes.

---

## Modelos tridimensionais

```
imagens/mascote/3d/
```

Reservado para futuros modelos tridimensionais.

Este diretório poderá conter:

- Blender
- STL
- STEP
- OBJ
- texturas
- renders

---

## README do diretório

O diretório `imagens/mascote/` deverá conter um README próprio documentando:

- organização;
- convenções;
- origem dos arquivos;
- formatos suportados;
- histórico de revisões.

---

## Preservação da identidade

Todos os ativos deverão manter fidelidade ao documento [identity.md](identity.md).

O arquivo

```
imagens/projetos/Comunica-CIATA/Logo-Comunica.png
```

permanece preservado como referência histórica e artística para toda futura produção de assets.
