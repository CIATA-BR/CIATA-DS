# Knowledge System

Esta área reunirá conhecimento reutilizável produzido pelos projetos do CIATA.

O conteúdo será organizado progressivamente em:

- decisões e índices de ADRs;
- RFCs e especificações;
- receitas de implementação;
- estudos de caso;
- lições aprendidas;
- anti-padrões;
- postmortems;
- pesquisas e referências;
- glossário institucional.

Conteúdo específico de um produto permanece no repositório do produto. Quando se tornar reutilizável, deve ser promovido para esta fonte canônica e referenciado pelo projeto de origem.
