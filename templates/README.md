# Modelos reutilizáveis

Esta pasta reúne estruturas iniciais para documentos recorrentes do CIATA-DS.

Os modelos funcionam como guarda-roupas: ajudam cada documento a sair vestido para a ocasião, sem obrigar todos a usar o mesmo paletó.

## Regras de uso

- copie o modelo adequado;
- substitua todas as marcações entre colchetes;
- remova seções realmente não aplicáveis e registre a justificativa quando necessário;
- preserve títulos claros e compreensíveis fora do contexto interno;
- use o código como apoio de localização, nunca como único nome;
- relacione o novo documento a SPECs, ADRs, checklists, playbooks e outros conteúdos pertinentes;
- revise a acessibilidade antes da publicação.

## Modelos disponíveis

- `proposta-de-mudanca-rfc.md` — proposta de mudança relevante;
- `padrao-pat.md` — padrão recorrente de produto, interface ou arquitetura;
- `receita-tecnica-rec.md` — solução técnica reproduzível;
- `base-de-conhecimento-kb.md` — aprendizado, solução, dúvida recorrente ou diagnóstico;
- `blueprint-bp.md` — estrutura reutilizável para iniciar projetos completos.

## Linguagem

Os títulos devem trazer o nome por extenso. Prefixos como RFC, PAT, REC, KB e BP aparecem para localização e rastreabilidade, não para criar um dialeto fechado.
