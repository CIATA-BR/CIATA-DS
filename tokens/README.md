# Tokens de design do CIATA

Esta pasta contém os valores oficiais da identidade visual do CIATA em formatos reutilizáveis por diferentes plataformas.

## Cores oficiais

- Amarelo: `#FFD000`
- Azul: `#005C99`
- Azul escuro: `#16365E`
- Cinza: `#B3B3B3`

## Tipografia

A família tipográfica institucional definida no Manual de Marca CIATA 2025 é **Segoe UI**.

## Formatos disponíveis

- `ciata.tokens.json`: formato neutro de design tokens
- `css/ciata.css`: variáveis CSS
- `android/colors.xml`: recursos de cor para Android
- `swift/CIATAColors.swift`: constantes para SwiftUI

## Acessibilidade

As cores de marca não devem ser aplicadas automaticamente como combinações de primeiro plano e fundo. Cada uso deve passar por verificação de contraste segundo WCAG, inclusive nos estados de foco, desabilitado, erro, sucesso, seleção e alto contraste.

Nenhuma informação deve depender exclusivamente da cor. Use também texto, forma, ícone com rótulo e estado programático apropriado.
