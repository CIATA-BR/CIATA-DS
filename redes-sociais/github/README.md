# GitHub

Ativos oficiais para a organização e os repositórios do CIATA no GitHub.

## Conteúdo previsto

- `banner/`: cabeçalhos e banners institucionais.
- `social-preview/`: imagens exibidas ao compartilhar repositórios.
- `avatar/`: versões do símbolo adequadas para recorte circular.
- `modelos/`: bases editáveis para novos projetos.
- `historico/`: versões substituídas que precisam ser preservadas.

## Acessibilidade

- O texto principal deve permanecer legível em telas pequenas.
- Informações essenciais não devem existir apenas dentro da imagem.
- Cada imagem publicada no repositório deve ter descrição textual próxima ou em catálogo.
- Contraste e hierarquia visual devem ser verificados antes da publicação.
