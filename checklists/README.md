# Checklists operacionais do CIATA

Os checklists transformam padrões, decisões e critérios de qualidade em verificações repetíveis.

## Regra de uso

- Um checklist não substitui julgamento profissional.
- Evidências devem ser registradas quando aplicável.
- Itens não aplicáveis devem receber justificativa.
- Falhas críticas impedem aprovação ou publicação.
- Acessibilidade deve ser validada por pessoas, com apoio de ferramentas automáticas.

## Identificação

Cada checklist recebe um código permanente no formato `CHECK-NNNN`.

## Catálogo inicial

- `CHECK-0001` — revisão manual de acessibilidade;
- `CHECK-0101` — QA funcional de produto digital;
- `CHECK-0201` — revisão de artefato visual;
- `CHECK-0301` — qualidade documental;
- `CHECK-0401` — preparação de release.

## Resultado

Cada execução deve registrar:

- projeto ou artefato avaliado;
- versão;
- data;
- responsável;
- ambiente e tecnologias assistivas;
- resultado de cada item;
- falhas encontradas;
- evidências ou links;
- decisão final.
