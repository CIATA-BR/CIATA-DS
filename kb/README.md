# Base de conhecimento

A base de conhecimento preserva respostas, diagnósticos e aprendizados que poderiam desaparecer em conversas, caixas de e-mail ou na memória de uma única pessoa.

## Conteúdos adequados

- perguntas frequentes;
- glossário em linguagem simples;
- solução de problemas;
- lições aprendidas;
- post-mortems sem culpabilização;
- limitações conhecidas;
- notas de compatibilidade.

## Princípios

- começar pela resposta mais útil;
- explicar siglas na primeira ocorrência;
- informar produto, versão, ambiente e data quando relevantes;
- separar fatos confirmados de hipóteses;
- incluir passos de verificação e recuperação;
- não registrar segredos, credenciais ou dados pessoais;
- garantir que títulos e links façam sentido fora do contexto visual.

## Identificação

Entradas permanentes podem receber o prefixo `KB`, acompanhado de um título descritivo.

Exemplo:

```text
KB-0001-erro-de-autenticacao-no-microsoft-graph.md
```

Na comunicação, prefira “guia para erro de autenticação no Microsoft Graph KB-0001” em vez de citar apenas o código.
