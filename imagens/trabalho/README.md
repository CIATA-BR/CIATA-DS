# Trabalho

Imagens de atuação profissional, colaboração e ambientes de trabalho.

## Regras

- representar pessoas com dignidade e autonomia;
- evitar estereótipos, infantilização e enquadramentos de piedade;
- registrar origem, licença ou autorização de uso;
- fornecer texto alternativo quando houver informação relevante;
- fornecer descrição longa para imagens complexas;
- evitar texto embutido quando o conteúdo puder ser apresentado em HTML;
- otimizar dimensões e formato para desempenho.

## Nomenclatura

Exemplos:

```text
pessoa-usando-linha-braille-001.webp
estudante-com-ampliador-eletronico-001.webp
reuniao-acessivel-com-interprete-de-libras-001.webp
```
