# Imagens

Este diretório reúne fotografias, ilustrações e imagens institucionais aprovadas para uso pelo CIATA.

## Organização sugerida

- `institucionais/`
- `eventos/`
- `projetos/`
- `equipe/`
- `ilustracoes/`
- `historico/`

Cada imagem deve possuir origem conhecida, autorização de uso quando necessária e descrição textual adequada para contextos acessíveis.
