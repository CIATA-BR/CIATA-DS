# Pessoas e tecnologia assistiva

Esta pasta reúne imagens de pessoas utilizando tecnologias assistivas em contextos de estudo, trabalho, mobilidade, comunicação, cultura, lazer e participação social.

## Categorias recomendadas

- `braille/`;
- `baixa-visao/`;
- `mobilidade/`;
- `comunicacao/`;
- `audicao/`;
- `educacao/`;
- `trabalho/`;
- `vida-cotidiana/`;
- `diversidade/`.

As categorias podem ser criadas conforme o acervo crescer. Não criar diretórios vazios apenas para antecipar uma estrutura futura.

## Representação

As imagens devem priorizar autonomia, naturalidade e contexto. A deficiência não deve ser tratada como espetáculo, tragédia, ornamento ou atalho emocional.

Consulte [`docs/uso-de-imagens.md`](../../docs/uso-de-imagens.md) antes de incorporar novos ativos.
