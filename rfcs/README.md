# Propostas de mudança (RFCs)

As RFCs registram mudanças relevantes antes da implementação. A sigla ajuda na identificação, mas o título e o texto devem permanecer claros para qualquer pessoa.

## Quando usar

Use uma proposta de mudança quando houver impacto em governança, arquitetura, acessibilidade, segurança, vários projetos ou tipos de artefato.

Correções editoriais e manutenção rotineira não precisam de RFC.

## Fluxo

1. Copiar o modelo oficial.
2. Explicar problema, contexto e pessoas afetadas.
3. Descrever proposta, alternativas, riscos e acessibilidade.
4. Abrir discussão pelo período definido.
5. Registrar decisão e documentos derivados.

## Estados

- Rascunho
- Em discussão
- Aceita
- Rejeitada
- Retirada
- Substituída

## Identificação

```text
RFC-0001-titulo-claro.md
```

O código nunca deve aparecer sozinho como título ou texto de link.
