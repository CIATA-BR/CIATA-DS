# Registro Mestre de Artefatos

Este é o inventário permanente dos artefatos oficiais do CIATA. Um identificador nunca deve ser reutilizado, mesmo após o arquivamento do item.

## Categorias iniciais

| Prefixo | Categoria |
|---|---|
| `LGO` | Logo |
| `SYM` | Símbolo |
| `ICO` | Ícone |
| `BAN` | Banner |
| `SOC` | Rede social |
| `TMP` | Template |
| `DOC` | Documento |
| `PAP` | Papelaria |
| `CRT` | Certificado |
| `IMG` | Imagem |
| `ILU` | Ilustração |

## Estados permitidos

`Ideia`, `Rascunho`, `Em desenvolvimento`, `Em revisão`, `Aprovado`, `Publicado`, `Em manutenção`, `Obsoleto` e `Arquivado`.

## Regras

- A inclusão de um código exige um passaporte de artefato.
- Alterações incompatíveis exigem nova versão ou novo identificador, conforme a natureza da mudança.
- Itens obsoletos permanecem no registro com indicação do substituto.
- O caminho deve apontar para o arquivo oficial, nunca para uma cópia temporária.
- Datas usam o formato ISO `AAAA-MM-DD`.
