# Referenciais regulatórios e de conformidade

Esta área organiza referenciais de acessibilidade que complementam a base canônica WCAG 2.2 do CIATA Design System.

O objetivo não é duplicar o texto normativo de cada padrão, mas registrar:

- qual versão é aplicável;
- quando o referencial deve ser usado;
- como ele se relaciona com WCAG;
- quais requisitos adicionais precisam ser avaliados;
- como registrar os resultados em um Accessibility Conformance Report (ACR).

## Regra de precedência

Quando um projeto estiver sujeito a obrigação legal, contratual ou regulatória específica, a versão formalmente aplicável desse referencial prevalece para fins de declaração de conformidade.

A adoção interna de WCAG 2.2 A e AA pela CIATA permanece como linha de base de qualidade, mesmo quando um referencial externo ainda incorporar uma versão anterior da WCAG.

Isso significa que atender à WCAG 2.2 não autoriza declarar automaticamente conformidade com EN 301 549, Revised Section 508 ou qualquer outro padrão: requisitos adicionais e regras de escopo precisam ser avaliados separadamente.
