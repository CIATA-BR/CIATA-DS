# Definição de pronto por disciplina

Esta área traduz a base canônica de acessibilidade do CIATA Design System em checklists curtos de entrega por disciplina.

Os checklists não substituem os padrões detalhados. Eles funcionam como porta de entrada para revisão antes de handoff, desenvolvimento, QA e release.

## Disciplinas

- [Design](design.md)
- [Conteúdo](conteudo.md)
- [Web](web.md)
- [Android](android.md)
- [iOS](ios.md)
- [QA](qa.md)

## Regra comum

Uma entrega não está pronta apenas porque o artefato da disciplina terminou. Ela deve preservar o contrato de acessibilidade até o uso real, com evidência proporcional ao risco e reteste quando houver alteração funcional.
