## Consistência visual

- [ ] mantém a silhueta canônica;
- [ ] mantém as proporções canônicas;
- [ ] mantém a linguagem de formas;
- [ ] mantém a paleta principal ou variante autorizada;
- [ ] mantém acessórios e traços permanentes;
- [ ] expressão e pose correspondem ao estado pretendido;
- [ ] continua reconhecível como o mesmo personagem em tamanho reduzido.

## Acessibilidade

- [ ] não contém texto essencial incorporado;
- [ ] não é a única fonte de erro, sucesso, alerta, instrução ou estado;
- [ ] detalhes essenciais não dependem apenas de cor;
- [ ] contraste com o fundo é suficiente para o contexto de uso;
- [ ] o tratamento como decorativo, informativo, funcional ou complexo está registrado;
- [ ] descrição alternativa ou equivalente textual está definida quando necessária;
- [ ] não reforça estereótipos ou infantiliza pessoas com deficiência;
- [ ] existe alternativa compatível com redução de movimento quando a versão final for animada.

## Resultado

- [ ] aprovado como referência canônica;
- [ ] aprovado como variante;
- [ ] ajustes necessários;
- [ ] rejeitado.
